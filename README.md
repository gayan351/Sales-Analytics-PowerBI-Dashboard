# Sales Analytics and Business Intelligence Dashboard

## Project Overview
This project focuses on analyzing sales data and developing an interactive Business Intelligence dashboard using Microsoft Power BI.

## Objectives
- Analyze total sales revenue and profit.
- Understand sales performance by country.
- Compare sales across different item types.
- Analyze yearly and quarterly sales trends.
- Compare online and offline sales channels.

## Tools and Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Business Intelligence

## Dashboard Features
- Total Revenue
- Total Profit
- Total Cost
- Units Sold
- Sales by Country
- Sales by Item Type
- Yearly and Quarterly Analysis
- Online vs Offline Sales
